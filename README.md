# 🌊🏄 Surf Run — Complete Arcade Edition

**RO:** Joc arcade mobile-first construit cu **HTML, CSS și JavaScript vanilla**, pornind de la o idee simplă de runner cu emoji și extins într-o experiență completă cu moduri de joc, progres permanent, shop cosmetic, misiuni, achievement-uri, efecte sonore, stropi pe ecran și setări de accesibilitate.

**EN:** A mobile-first arcade runner built with **HTML, CSS and vanilla JavaScript**, starting from a simple emoji-based runner concept and evolving into a complete arcade experience with game modes, permanent progression, cosmetic shop, missions, achievements, sound effects, screen splash effects and accessibility settings.

---

## 🇷🇴 Descriere

**Surf Run — Complete Arcade Edition** este un mini joc arcade în care controlezi un surfer, eviți obstacole precum rechini, stânci sau obiecte aeriene, colectezi monede și diamante, deblochezi skin-uri și încerci să obții un scor cât mai mare.

Proiectul pune accent pe:

- experiență bună pe mobil;
- gameplay rapid și clar;
- feedback vizual și sonor;
- progres salvat local;
- moduri multiple de joc;
- accesibilitate și opțiuni de personalizare;
- cod scris fără framework-uri.

---

## 🇬🇧 Description

**Surf Run — Complete Arcade Edition** is a small arcade game where you control a surfer, dodge obstacles such as sharks, rocks and flying hazards, collect coins and gems, unlock skins and try to reach the highest score possible.

The project focuses on:

- mobile-first gameplay;
- fast and readable interaction;
- visual and audio feedback;
- local saved progress;
- multiple game modes;
- accessibility and customization settings;
- framework-free implementation.
